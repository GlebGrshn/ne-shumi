# НЕ ШУМИ

Хоррор-прятки для Яндекс Игр. Он слепой. Он слышит.

## Концепция

Дом в темноте. Игрок собирает ключи и ищет выход. **Слушатель** — слепой монстр,
охотится только на звук: бег слышно через стены, шаг почти нет. Стоишь — он
проходит в метре и не замечает. С шестой ночи появляется **Смотритель** —
глухой, но видит далеко узким светящимся лучом. Контрприёмы противоречат друг
другу: от луча убегают, а бег зовёт Слушателя.

Хоррор держится на звуке: сердцебиение ускоряется по мере приближения монстра
(даже за стеной), его шаги слышны сквозь стены. Весь звук синтезируется
WebAudio — в проекте ноль аудиофайлов.

### Звук

Чтобы синтез не звучал «пиксельно», всё построено на трёх правилах:

1. **Общая шина реверба** — свёртка с сгенерированным импульсом (сглаженный шум
   с экспоненциальным затуханием, 2.9 с, тёмный). Именно объём отличает живой
   звук от писка из динамика; у каждого источника своя доля посыла — чем дальше
   и чем больше стен, тем больше хвоста и меньше прямого сигнала.
2. **Никаких чистых тонов на переднем плане.** Ключи — негармоничные обертоны
   (1 : 2.41 : 3.83), как у настоящего металла. Шаги — розовый шум плюс низкая
   «телесная» составляющая. Скрип — полосовой фильтр с дребезгом амплитуды.
3. **Разброс** по высоте и времени в каждом срабатывании, мягкие атаки.

**Готовые записи** (`assets/audio/`) перекрывают синтез, если файл есть:
`scream_listener`, `scream_watcher`, `thunder` — расширение `.ogg`, `.mp3` или
`.wav`, ищутся в этом порядке. Нет файла — играет синтез, игра не ломается.
При воспроизведении накладывается фейд в конце: часть заготовок обрывается на
полной громкости и без него слышен щелчок.

Синтезированный скример собран как голос, а не как «низкая пила»: гортанный
источник из трёх расстроенных пил с дрожью и субгармоникой, поверх — три
форманты, затем мягкий клиппинг (`WaveShaper`) и шумовой выдох. Без дисторшна
любой синтез звучит стерильно и не пугает.

**Музыка** — медленный тёмный эмбиент, живёт непрерывно и не обрывается на
экранах: дрон из двух расстроенных пил, пэд-кластер с негармоникой и очень
долгой атакой, текстура из розового шума в плывущем фильтре. Тональность
меняется раз в ~40 с. Раз в 15–40 с — удар глухого «колокола» или скрип
оседающей балки. Отдельный слой тревоги (тритон) поднимается по близости
монстра и особенно в погоне.

### Чем игрок себя выдаёт

| Источник шума | Радиус | Обходится |
|---|---|---|
| Бег | 8 клеток | тихие кроссовки (за рекламу) |
| Скрипучая половица | 6.5 | обойти — но её видно только в свете фонаря |
| Загнанное дыхание | 4.2 | отдышаться, стоя на месте |
| Дверца шкафа | 3.5 | — |
| Шаг | 1.7 | — |

Бежать бесконечно нельзя: выносливости на **4.2 секунды**, потом переход на шаг
и громкое дыхание ещё 4 секунды. Кроссовки глушат бег, но не дыхание.

## Контент

- **Ночи не кончаются.** Первые восемь — сюжетная арка с фиксированными
  текстами; после них дом «начинает считать заново», и ночи идут дальше без
  предела. Сложность растёт по насыщающейся кривой `sat(x) = x/(x+half)`:
  быстро в начале, затем упирается в потолки. Погоня не превысит **5.05**
  против бега 5.2, слух — 1.65, дом — 48×36. Сотая ночь тяжелее восьмой, но
  проходима; укрытий тоже становится больше (6 → 17), иначе поздние ночи
  превратились бы в лотерею.
- **Модификаторы ночи** с 4-й: каждая третья ночь чистая, подряд не
  повторяются, злые (`twins`, `silence`) открываются только с 7-й.
  Ночи 5 и 6 всегда чистые — на них игрок учит шкаф-предателя и Смотрителя.

  | Модификатор | Что меняет |
  |---|---|
  | ГРОЗА | раскат грома глушит твой шум на 85 %, но вспышка молнии выдаёт тебя Смотрителю и он бросается в погоню |
  | ТЕМНО | фонарь светит вдвое ближе, зато монстры медленнее |
  | СКВОЗНЯК | дом сам издаёт ложные шумы вдали — Слушатель уходит на них |
  | ИХ ДВОЕ | вместо Смотрителя второй Слушатель |
  | ТИШИНА | музыка выключается совсем |
- **С ночи 3** Слушатель обыскивает шкафы рядом с местом, где что-то слышал —
  прятки перестают быть безопасными сами по себе.
- **Ночь 5** — шкаф-предатель: один из шкафов занят.
- **С ночи 6** — Смотритель и только две жизни.
- **С ночи 7** Слушатель бежит с упреждением: не за тобой, а туда, где ты будешь.
- **Подвал** — бесконечный режим после восьмой ночи, счёт = этажи.
- Карты **генерируются процедурно** (комнаты + коридоры, проверка связности),
  двух одинаковых ночей не бывает.
- **«Те, кто заходил до тебя»** — локальный лидерборд с вымышленными записями:
  подстраивается под рекорд игрока, первые забеги гарантированно бьют пару
  строчек, топ недосягаем.

## Монетизация (SDK Яндекс Игр)

| Слот | Где | Что даёт |
|---|---|---|
| Rewarded | экран входа в ночь / пауза | тихие кроссовки: бесшумный бег до конца ночи |
| Rewarded | экран поражения | ещё одна жизнь вместо рестарта (1 раз за ночь) |
| Rewarded | кнопка в HUD | подсветить все ключи на 5 с (кулдаун 60 с) |
| Interstitial | между ночами + в игре раз в ~90 с | показ откладывается, пока идёт погоня или монстр ближе 3 клеток |
| Banner | только меню | — |

Игра полностью проходится без единого просмотра рекламы.

## Соответствие требованиям Яндекс Игр

| Требование | Где реализовано |
|---|---|
| SDK подключён с `/sdk.js` | `index.html`, с фоллбеком в mock-режим |
| `LoadingAPI.ready()` | `SDK.ready()` в конце `boot()` |
| `GameplayAPI.start/stop()` | `enterPlay`, `pauseGame`, `gameOver`, хуки рекламы |
| `game_api_pause` / `game_api_resume` | `SDK.onPauseResume()` → `Sound.setSuspended` + пауза |
| Звук глушится при потере фокуса | `visibilitychange` → `setSuspended` (плюс `ctx.suspend()`) |
| Звук и геймплей паузятся на рекламе | `SDK.setAdHooks()` — единая точка для всех показов |
| Реклама только через SDK | `sdk.js`, сторонних сетей нет |
| Rewarded только по кнопке, награда — бонус | три кнопки; игра проходится без единого показа |
| Гостевой вход с сохранением | `getPlayer({scopes:false})` + localStorage |
| Прогресс не теряется при перезагрузке | `SDK.save()` в localStorage и облако |
| Рекорд для бесконечного режима | `basementBest`, `bestNight` |
| Нет внешних ссылок и абсолютных URL | все пути относительные |

`window.blur` намеренно **не** используется: на Яндексе игра работает в iframe,
и клик мимо неё гасил бы звук прямо посреди партии. Для этого есть
`game_api_pause`.

## Запуск локально

```
node server.js          # http://localhost:5173, SDK в mock-режиме (заглушки рекламы)
```

Проверка с настоящим SDK:

```
npx @yandex-games/sdk-dev-proxy -p 5173
```

## Сборка для модерации

```
powershell -ExecutionPolicy Bypass -File build.ps1   # -> neshumi.zip
```

В архив попадают только `index.html` и `js/`.

## Управление

- **WASD / стрелки** — идти, **Shift** — бег (шумно), **E / Space** — шкаф и дверь, **Esc** — пауза.
- Телефон: вести пальцем от точки касания; дальний край — бег; контекстная кнопка действия.

## Структура

```
index.html    — разметка, все экраны UI, стили
js/config.js  — кривая сложности и все числа баланса
js/sprites.js — загрузка и чистка спрайтов из assets/ (с фоллбеком)
js/textures.js— процедурные текстуры (доски, штукатурка, бетон, дерево)
js/mapgen.js  — генератор дома (комнаты, коридоры, ключи, шкафы, половицы)
js/entities.js— игрок + ИИ Слушателя и Смотрителя
js/render.js  — рендер: темнота, полигон видимости, память карты, луч, скример
js/audio.js   — весь звук (WebAudio-синтез): сердце, шаги, дрон, скример
js/sdk.js     — обёртка SDK Яндекса: реклама, сохранения, mock-режим
js/board.js   — фейковый лидерборд
js/input.js   — клавиатура + тач-джойстик
js/main.js    — цикл, состояния, ночи, подвал, реклама, сейвы
server.js     — статика для локальной отладки (+POST /shot для скриншотов)
```

## Графика

**Спрайты** (`assets/`, загрузка в `sprites.js`) — игрок в 4 ракурсах + циклы
ходьбы/бега, оба монстра в ракурсах и позах по состояниям, два лица для
скримеров. Файлы приходят с альфой, но в вырезах остаются обрывки подписей с
исходных листов, поэтому при загрузке каждый спрайт чистится: оставляем только
самый крупный связный объект, потом обрезаем по содержимому и поднимаем яркость
(концепты сняты в темноте, а поверх ложится ещё и слой мрака — без этого фигуры
превращаются в чёрные кляксы). **Если папки `assets/` нет — игра молча
переключается на векторную отрисовку и остаётся полностью играбельной.**

Спрайты не вращаются: ракурс выбирается по направлению (`front/back/left/right`,
боковой отзеркаливается), на ходу добавляется покачивание. **Осторожно с
именами файлов игрока:** `player_idle_left/right` — это положение камеры, а не
направление взгляда (на «виде слева» персонаж развёрнут вправо), поэтому в
манифесте они намеренно поменяны местами. У монстров такой инверсии нет —
`side` смотрит вправо, как и ожидает код. Поза монстра зависит
от состояния ИИ: погоня → `attack`, поиск → `listen`/`notice`, патруль →
направленный вид.

**Текстуры** генерируются кодом при загрузке (`textures.js`):
бесшовный value-noise, из него доски с волокном и швами, штукатурка с трещинами
и осыпями, бетон подвала, дерево шкафов. Тайлится по мировой сетке через
`createPattern` + `setTransform`, поэтому швов между клетками не видно.
Перекрасить всё — это одна строка `buildTextures()`.

## Баланс — самые хрупкие числа

- Бег игрока **5.2** против погони Слушателя **4.34→5.01** (ночь 1→8). На восьмой
  ночи разница почти нулевая, а выносливости хватает на 4.2 с — оторваться уже
  нельзя, можно только перестать шуметь.
- Слышимость бега **8 клеток**, каждая стена глушит на 45 %.
- Фонарик: конус **7** клеток, вокруг себя **3.4**.
- Слух монстра растёт ×0.94 → ×1.36 за 8 ночей.
